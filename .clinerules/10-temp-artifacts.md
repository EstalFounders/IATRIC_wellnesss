# Temp artifacts
- Always delete throwaway scripts, helper files, preview pages and generated sample
  artifacts (e.g. `tmp-*.mjs`, `scripts/tmp-*.mjs`, scratch `*.py`, sample images/SVGs)
  once the task that created them is done. Leave no scaffolding behind.
- Only keep a file if it is a real, committed part of the project or the user explicitly
  asks to keep it.
